# NOVA — FAQ Accordion

A clean, responsive FAQ accordion built with HTML, CSS, and JavaScript. NOVA focuses on simple interaction, smooth transitions, and a professional help-center style interface.

## ✨ Features

* Expand and collapse FAQ answers
* One FAQ opens at a time
* Smooth accordion animations
* Dynamic plus/minus icons
* Responsive mobile layout
* Sticky navigation
* Smooth scrolling
* Clean and accessible UI
* Contact CTA section

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## 📁 Project Structure

```text
nova-faq/
├── index.html
├── style.css
└── script.js
```

## 🎨 Design

NOVA uses a soft, modern visual style with:

* Warm cream backgrounds
* Forest green accents
* Subtle brown tones
* Rounded UI elements
* Clean typography
* Minimal animations

The goal was to create a help-center interface that feels simple, polished, and easy to navigate.

## ⚙️ How It Works

JavaScript controls the accordion state.

When a question is clicked:

1. The selected FAQ opens.
2. Any previously opened FAQ closes.
3. The icon changes between `+` and `−`.
4. CSS handles the visual transition.

## 📱 Responsive Design

The layout adapts to:

* Desktop
* Tablet
* Mobile

Spacing, typography, navigation, and FAQ cards adjust for smaller screens.
